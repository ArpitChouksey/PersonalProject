# SRE Automation Platform

Self-Service SRE Automation Platform built using GitLab CI/CD.

## Objectives

- Grafana Dashboard Automation
- Grafana Alert Automation
- Kibana Logging Automation
- Jaeger Tracing Automation
- AWS Observability Automation
- Future AI-Assisted SRE Operations

## Phases

1. Grafana Automation (Local)
2. Kibana Automation (Local)
3. Tracing Automation (Local)
4. Grafana Automation (AWS)
5. Kibana Automation (AWS)
6. Tracing Automation (AWS)
7. SRE Service Catalog
8. AI-Powered SRE Automation
